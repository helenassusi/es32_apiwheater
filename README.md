# 🌦️ ESP32 + MQTT + OpenWeatherMap

Projeto desenvolvido para consultar informações climáticas de diferentes cidades utilizando a API OpenWeatherMap e realizar a comunicação por MQTT com o ESP32.

## 📌 Sobre o projeto

O usuário informa uma cidade e seleciona o país. O sistema consulta a API OpenWeatherMap e apresenta:

- 🌡️ Temperatura
- 💧 Umidade
- 🌬️ Velocidade do vento
- ☀️ Sensação térmica
- 🧭 Pressão atmosférica
- 🌎 Cidade atual

Os dados também são enviados utilizando MQTT.

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- OpenWeatherMap API
- MQTT
- MQTT.js
- Chart.js
- HiveMQ
- ESP32
